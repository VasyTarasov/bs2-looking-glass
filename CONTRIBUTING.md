# Contributing

Keep concrete behavior, game-build assumptions and reproduction steps clear. Documentation is English-first with a linked Russian guide. Binding groups stay at ten entries or fewer; starting/final weapons and selected-ID/live-stat distinctions remain independent.

Run the repository audit and game-free tests. Native tests require an isolated synthetic fixture and the hardened launcher. Never commit game assets, saves, diagnostics, credentials or copied research dumps. Review generated data and attribution before changing allowlisted hashes.

Do not add a stable release workflow or advance to 1.0 without an explicit decision. Follow the development sequence in CHANGELOG.md.
