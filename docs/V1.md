# Version 1.0

[Home](../README.md) · [Русский](RU.md)

This release reorganizes feature selection and shared battle services. It retains the previously verified formulas, factual data, original engine and native graphics helper.

The installer and in-game module selector share generated bilingual names, descriptions and macro dependencies from `modules.json`. `tools/build_modules.py` generates Russian runtime metadata; `tools/build_localization.py` generates the English runtime. Installer interface language remains independent of the installed game's language.

The installer has seven sections arranged in three columns, with all 20 choices visible in one compact window, native hover tooltips, keyboard-focus descriptions and a persistent description area. The in-game selector wraps descriptions and applies dependency changes when toggled. Enabling macros enables groups; disabling groups disables macros. Neither choice enables automatic support or loadouts.

Shared action facts are in `action_rules.rb`; manual weapon nomination is in `combat_selection.rb`. Automatic use is loaded only for `battle_support`. Its policy remains battle-only and per-row opt-in. Automatic support can run without group windows. Advanced Legacy uses the common native command/list pipeline and can coexist with groups. Map highlighting and presentation acceleration have independent load gates.

Preview configuration migration merges reference/effects and basic conveniences, retains existing independent choices, infers previously available macros, and keeps newly explicit automatic support off. Fresh installs default to all features except Legacy, automatic support and diagnostics. Existing diagnostic preferences are preserved on update.

The forecasting engine's supported scope and historical F12 limitation remain as documented. Version 1.0 does not establish the cause or repair of the historical native F12 crash, and acceptance tests are not a complete story playthrough.

Source, updater, native and visual acceptance evidence for this release is summarized in [QA](QA.md). Historical suites and documentation remain available for traceability.
