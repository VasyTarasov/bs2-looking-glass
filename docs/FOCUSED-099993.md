# Focused references — 0.99993-dev

Normal help uses the original item/skill/equipment description directly, with the original two-line geometry and escape handling. It no longer receives catalog prose, automation rules or additional panels. Lore is loaded from the player's game at runtime, not copied into the package. HD and F7 remain the mechanics views.

## Information policy

Materials have one generic crafting/upgrade sentence. Ingredient examples, recipe counts, store/event identifiers, generic script caveats, unconditional free-cost/normal-action lines, resource sign tutorials and repeated variable legends are omitted. Important drawbacks, actual costs, state effects, TP rewards, book learning marks and concrete story purposes remain. Equipment stat families are grouped; important drawbacks precede bonuses. F7 no longer stacks the old verbose description over the new catalog summary. Source catalog data remains intact and read-only.

The HUD shows all ten digit entries. It starts no numerical sequence calculation while navigating new rows, waits 160 ms after selection settles and shares bounded completed results with F7 costs/estimates. Formula roles are pale blue RGB(218,234,250) for the user and pale red RGB(250,224,224) for the target in both native F7 and the actual HD compositor. Native measurement ignores the inline markers. Exact AST parentheses and integer/float division semantics are preserved. A constant zero or a base ten alongside percentage resource effects is not displayed as a separate main formula; the numerical executor still includes it.

Colored stat souls are consumed by the native common event although their database consumable flag is false. Player text now describes the actual chosen-quantity consumption. Their mechanics and event execution are unchanged.

## Manual battle automation

Every battle starts without automatic rows. D on a specific eligible battle item/Gun Break toggles only that row. Definitions live only in the current battle; saved activation lists and old reserve/limit files are ignored. Outside-battle activation, group/master activation, configurable reserves, spending caps and their settings/experimental mode screens are removed. Native stock, usability and state-driven need are preserved internally. Intentional madness is preserved. Fire resin keeps its native thaw when fire renewal is due; the separate thaw-mode setting is removed. Hlanith wine retains its native one-use battle policy. Field stealth remains a separately chosen field-skill action with explicit feedback rather than replacing its lore description.

The custom defeat screen and associated retry implementation are removed. Battle statistics and the original game's defeat handling remain. Updates remove only the retired defeat/retry module flags and retain other settings and saves.

## Forecast scope and evidence

Corpse Dragon Threat entries use five native internal applications for one command. An unrelated resurrection trait on an unharmed outgoing attacker no longer rejects the entire multi-hit estimate. Potential recipient death/revival, counters, reflection and other unsupported transitions still retain explicit limits. The controlled five-hit result is checked against 16 seeded native executions; this is not a claim that every boss phase is fully modelled.

Final native/profile counts, actual GPU screenshots, preservation checks and package hashes are recorded in the local delivery report and [QA](QA.md). The historical F12 issue is not established as fixed. No release or network publication is created.
