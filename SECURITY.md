# Privacy and reporting

The mod does not automatically upload diagnostics, saves or profiles. Steam integration uses the locally running client for its intended overlay/screenshot functionality.

Do not commit game runtimes, engine/Steam libraries, archives, saves, sessions, credentials, personal configuration, conversation exports or diagnostic ZIPs. Git ignores, the repository auditor and the asset allowlist are complementary safeguards.

The optional collector writes a local archive which may contain labels, profiles and paths. Review before sharing. Never add automatic collection/upload to CI or issue workflows.

Report version, game edition, enabled modules, steps and a minimal redacted error. Do not upload your game folder. A dedicated private security-reporting endpoint is not configured; do not place sensitive material in public issues.
